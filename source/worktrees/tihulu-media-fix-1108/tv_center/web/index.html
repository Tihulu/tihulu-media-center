1 · WebUSB receiver (preferred)

Select the Hauppauge WinTV-soloHD directly in a compatible Chromium-based browser. USB permission and actual DVB-T2 decoding are separate capabilities; this preview can detect the USB device but does not yet tune/decode television through WebUSB.

No USB access requested. Firefox and Safari do not support WebUSB.

Matches USB 2040:8268 only; never claims RTL-SDR / ADS-B ownership. Does not detach a Linux DVB kernel driver.

2 · Watch on iPhone / Android (paired Wi-Fi)

Plug the DVB-T2 USB tuner into the host computer or Raspberry Pi. In native TV Center, tune a channel, enable Allow phone / tablet on trusted Wi-Fi, then on the phone open the displayed http://HOST-IP:8769/. Enter the six-digit pairing code shown on the host; no long token is needed. Enable Share live H.264/AAC video on the host for an optional real TV stream.

Safari on iPhone plays HLS natively; Android Chrome uses hls.js. The host and phone must share trusted Wi-Fi. Never expose HTTP port 8769 to the public Internet.

3 · Local receiver bridge (optional)

For real DVB-T2 reception, live subtitles and Teletext, run TIHULU TV Center on Debian / Pop!_OS / Pi OS, enable its bridge only when desired and paste the temporary session token. It does not use browser WebUSB.

GitHub Pages cannot directly access Linux DVB hardware. Browser loopback permissions may vary.
